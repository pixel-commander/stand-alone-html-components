PATHS
=====

[root] is the only fixed path. Every other path is written relative to
[root], or relative to the file doing the referencing.

    [root] = c:\stand-alone-html-components

From the loader
---------------

The loader sits at [root], one level above the shared area:

    __shared/css/theme.css
    __shared/css/grid.css
    __shared/css/page.css
    __shared/components/item-list/item-list.css
    __shared/components/item-list/item-list.js

The shell fetches what a component is made of and compiles it in the page:

    projects/<name>/<name>.jsx
    projects/<name>/script.js
    projects/<name>/styles.css

A component that draws has its geometry fetched first:

    projects/<name>/generate<Name>.js

From inside a project
---------------------

A component carries no runtime of its own. React, Tailwind, the compiler and
the plotting library are the shell's, and a component names none of them.

Paths within a project are relative to the project folder itself:

    <name>.jsx
    script.js
    styles.css

A project that draws keeps its geometry beside the rest:

    generate<Name>.js

A project that carries assets keeps them beside the rest:

    icons/<name>.svg

From the automation
-------------------

All four sit two levels inside the shared area and reach [root] from
there. They are run from anywhere, by path:

    node __shared/automation/add-new-project/add-new-project.mjs <name>
    node __shared/automation/install-new-component/install-new-component.mjs <name> <repo>
    node __shared/automation/serve-the-shell/serve-the-shell.mjs

add-new-project reads the template and writes a project:

    __shared/__template/               read
    projects/<name>/                   written
    component-name.jsx                 renamed to <name>.jsx
    index.html                         the array in the shell, appended to

install-new-component reads a package and writes into a repo that is not
this one. The repo is given on the command line, and [repo] is whatever was
passed:

    projects/<name>/                   read
    [repo]/nx.json                     read, to check it is a workspace
    [repo]/libs/cds/react/ui/<name>/   written by the repo's own generator
    [repo]/libs/cds/react/ui/<name>/src/lib/
                                       where the package is unpacked
    [repo]/libs/cds/react/ui/<name>/README.txt
                                       the project README, moved up
