RULES — for Claude
==================

Do not leave comments in new code. All commentary goes into a README.txt.
Never reference paths in a README. README files describe functionality
only — paths belong in PATHS.txt.

Never say something is done when it is not. Report what was actually
changed, not what was intended or approximated. If the work was
interpreted rather than followed literally, say which, and say so before
describing the result.

Do not start until told to go. Let the whole request arrive first — more of
it is usually still coming. Hold every question until the end, ask them
together, then begin.

Leave existing comments alone. Do not rewrite, extend, or improve them.

Work inside one component at a time. Do not edit, refactor, or align
another component while working on this one.

Do not touch the shared area unless asked. A second component needing the
same thing is not reason enough to hoist it — ask first.

The template is a copy-me starting point, not a base to inherit from.
Copying it yields an index.html linking its own stylesheet and script,
nothing more.

Never rename anything that already exists unless you are copy/pasting a
template — files, folders, classes, variables, functions, ids, data
attributes. A name already written is the name that stays.

Case: variables inside functions snake_case; file-scope constants
SCREAMING_SNAKE_CASE; functions camelCase; classes PascalCase.

Minimal DOM. Only the elements the layout actually requires — no wrapper
elements between logical levels, unless one was asked for.

Ask rather than assume when two readings would produce different work.

Say what was done plainly. If something was skipped or is broken, say so.

No style tag in the shell's HTML, and no inline style attributes for
anything that is not data-driven. CSS lives in a stylesheet.

The shared area serves the wrapper only. It is not a library for the
stand-alones. A component brings its own CSS and its own JavaScript and
inherits nothing from the shell.

A project ships on its own. It is converted to a React package and leaves,
carrying everything it needs, so nothing it depends on may live in the
shared area.
