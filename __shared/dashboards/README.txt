DASHBOARDS — empty on purpose.

The tier exists so the guide has a shape to grow into, and so the first
dashboard has an obvious place to land. A dashboard follows the same folder
template as a page:

  <Name>/
    css/<name>.css
    js/<Name>.html

A dashboard composes components; it does not define atoms, and it does not
write its own grid templates beyond the ones grid.css already has.
